SECRET SERVICE — V1
====================

Cette V1 est une interface front-end de démonstration.

Connexion de démonstration :
Identifiant : agent0247
Mot de passe : secret123

Important :
- Les comptes, missions, rapports, etc. sont actuellement des données de démonstration.
- Pour un vrai système multi-utilisateurs avec données persistantes, il faudra connecter une base de données/authentification (par exemple Supabase).
- Ne pas utiliser le mot de passe de démonstration en production.

Publication simple :
1. Crée un compte GitHub.
2. Crée un repository public nommé secret-service.
3. Téléverse index.html, style.css, script.js et README.txt.
4. Dans Settings > Pages, choisis "Deploy from a branch", puis la branche main et le dossier /root.
5. GitHub affichera l'adresse publique du site.
