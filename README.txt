SECRET SERVICE V2 — SUPABASE

Cette version remplace le faux login agent0247 par Supabase Auth.

Installation GitHub :
1. Dans le repository Secret-Service, remplace index.html, style.css et script.js par ceux-ci.
2. Commit changes.
3. Attends la mise à jour GitHub Pages puis recharge le site avec Ctrl+F5.

Connexion :
- utilise l'adresse e-mail de ton utilisateur Supabase
- utilise TON mot de passe Supabase (ne le partage pas)

Fonctionnel :
- connexion réelle Supabase
- profil Direction
- liste des profils
- rôles
- permissions
- activation/désactivation via l'écran Modifier

À faire ensuite :
- création de nouveaux utilisateurs directement depuis le portail Direction.
Cette action nécessite une fonction serveur Supabase pour ne jamais exposer une clé administrateur dans GitHub.
